Avoid using absolute paths like this:

5.2 Shannon

\(H' = - \sum_i^n p_i\mathrm{log}p_i\), where \(p_i\) is the relative abundance for species i.

shannon <- function(abund) {
  p0 <- abund / sum(abund)
  p <- p0[p0 > 0]
  -sum(p * log(p))
}
apply(samp, 1, shannon)

6.2.1 MPD

\(MPD = \frac{2}{n(n-1)} \sum_{i<j} \delta_{i,j}\), where \(n\) is the number of species in the community and \(\delta_{i,j}\) is the distance between species i and j. Each distinct species pair is counted once.

res_mpd <- mpd(samp, cophenetic(phylo))
res_mpd
[1]       NA 1.568182 1.454545 1.606061 1.636364

The above vector shows MPD for each site.

6.2.2 MNTD

\(MNTD = \frac{1}{n} \Sigma^n_i min \delta_{i,j} \; i \neq j\), where \(min \delta_{i, j}\) is the minimum distance between species i and all other species in the community.

res_mntd <- mntd(samp, cophenetic(phylo))
res_mntd
[1]       NA 1.181818 1.181818 1.295455 1.272727

7 Functional metrics

7.1 Community weighted means (CWM)

\[ \mathrm{CWM}_i = \frac{\sum_{j=1}^n a_{ij} \times t_{j}}{\sum_{j=1}^n a_{ij}} \]

or

\[ \mathrm{CWM}_i = \frac{\boldsymbol{a_i} \cdot \boldsymbol{t}}{\sum_{j=1}^n a_{ij}}, \]

where \(a_{ij}\) is the abundance of species j in community i, and \(t_{j}\) is a trait value of species j.

Standardized effect size (SES)

How different is the observed MPD from a random expectation? Here, the null model shuffles species labels in the trait distance matrix, using all 77 species with trait data as the species pool. The community matrix stays unchanged, so each site’s species richness is preserved.

Let’s compare the observed MPD of Site2 with 999 randomized values. We use the same seed and label shuffles as above to reproduce its null distribution.

site <- "Site2"
observed_mpd <- res_ses_mpd[site, "mpd.obs"]

set.seed(123)
null_mpd <- replicate(999, {
  shuffled_dm <- taxaShuffle(trait_dm)
  mpd(samp[site, , drop = FALSE], shuffled_dm)
})
ggplot(tibble(MPD = null_mpd), aes(x = MPD)) +
  geom_histogram(bins = 30, fill = "grey80", color = "white") +
  geom_vline(aes(xintercept = mean(null_mpd), color = "Null mean"),
             linetype = "dashed", linewidth = 0.9) +
  geom_vline(aes(xintercept = observed_mpd, color = "Observed MPD"),
             linewidth = 1) +
  scale_color_manual(values = c("Null mean" = "grey30", "Observed MPD" = "#D55E00")) +
  labs(title = paste(site, "MPD: observed vs. null expectation"),
       x = "MPD (trait distance)", y = "Number of randomizations", color = NULL) +
  theme_bw() +
  theme(legend.position = "top")

SES expresses the difference between the observation and the null mean in units of the null standard deviation:

\[ SES = \frac{MPD_{obs} - \overline{MPD}_{null}}{SD(MPD_{null})} \]

(observed_mpd - mean(null_mpd)) / sd(null_mpd)
[1] -1.814963
res_ses_mpd[site, "mpd.obs.z"]
[1] -1.814963

These two values are the same. A negative SES means smaller trait distances than expected (clustering); a positive SES means larger distances (overdispersion). SES does not require a normal null distribution, and its sign alone does not establish statistical significance or identify an ecological process.
